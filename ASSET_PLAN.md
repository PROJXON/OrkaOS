# OrkaOS Overview Asset Plan — Modular System Pass

## Ecosystem / “What feels stuck first?” explorer
**Medium:** Modular vector assets + coded interaction.

**Assets:** `topology-field.svg`, `current-ribbon.svg`, `node-shell.svg`, `navigation-dial.svg`, existing OrkaOS logo.

**Why:** The ecosystem is an interactive navigation system, not an illustration. Code retains the recommendation state, route, progressive adoption, app inspection, autoplay demonstration, accessibility, and responsive layout; reusable assets provide visual finish and brand continuity.

## Pod / Flow / Slipstream / Ecosystem
**Medium:** Modular instrument assets + coded state system.

**Assets:** `navigation-dial.svg`, `pod-member.svg`, `current-ribbon.svg`, `slipstream-streak.svg`, `node-shell.svg`, `topology-field.svg`, existing OrkaOS logo.

**Why:** One stable instrument can demonstrate four behaviors. Code switches the active layers: formation for Pod, continuity for Flow, directional acceleration for Slipstream, and surrounding nodes for Ecosystem.
