# OrkaOS Overview Redesign

The Overview folder now introduces OrkaOS as a five-chapter story for someone encountering the product for the first time.

## Story structure

1. **Start Here** — Defines OrkaOS in plain English: Google Workspace plus focused OrkaApps equals a synchronized pod.
2. **The Story** — Begins with the fractured group-project problem and follows the coaching insight, workflow model, pod metaphor, and organic growth into a micro-stack.
3. **How It Works** — Explains the people-centered “OS,” multi-entry ecosystem, progressive app adoption, app series, and central hub.
4. **The Orka Way** — Demonstrates the three-pane interface and explains Pod, Flow, Slipstream, Ecosystem, white-labeling, and the calm Google-plus-macOS feel.
5. **Is It for You?** — Clarifies the ideal audience, non-fit cases, starting pains, FAQs, and next steps.

## Main implementation files

- `src/OverviewStory.jsx` — narrative content and chapter components
- `src/OverviewStory.css` — story layouts, visuals, responsive behavior, and dark-mode-compatible styling
- `src/App.jsx` — overview navigation and routing integration

The production-ready static output is included in `dist/`.
